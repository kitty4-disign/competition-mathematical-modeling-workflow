# 竞赛论文自然表达与证据完整性审阅

## 目的与边界

本参考用于在模型、计算和验证已经完成后，提升竞赛数学建模论文的**自然性、可读性和论证密度**。目标不是规避任何 AI 检测、隐藏工具使用或伪造作者经历，而是删去空泛、模板化和证据脱节的表述，使每个判断都可追溯到题目、数据、公式、实验、图表或可靠来源。

若用户要求绕过检测、伪造人工写作痕迹、编造决策过程、改写事实以规避审查，停止该目标；保留合规披露、事实核验和赛事规则检查。

## 何时使用与所需输入

在论文写作阶段完成初稿后、终检前使用。先准备当前章节草稿、模型证据包、结果表/图、符号表、引用清单和赛事文体要求。若有参赛队既有的人工写作样本，可用它校准句长、术语密度和语气；不得模仿无关作者的独特文风。

未能回链到证据的内容不能以润色掩盖。将缺口标为 `【待补证据：需要的图表、计算、来源或限制】`，或删去该句。

## 三轮审阅

### 第一轮：主张—证据对齐

逐段标记关键主张，并判断其属于题设事实、数据观察、模型假设、计算结果还是解释性推断。对结论性句子核对：数值是否与表图一致，比较是否给出对象/指标/情景，因果、最优性和稳健性是否有相应设计或检验支撑。

| 表述类型 | 可接受的证据 | 写作要求 |
|---|---|---|
| 计算结果 | 可复算输出、表格或图 | 写清对象、指标、单位、情景和比较基准。 |
| 模型解释 | 公式、参数含义、机制假设 | 写明适用条件，不把假设写成事实。 |
| 稳健性判断 | 灵敏度、替代模型、边界测试或残差检查 | 说明扰动范围、方法与稳定的具体边界。 |
| 外部事实 | 可追溯的一手来源或已核验数据 | 给出准确引用，不用“研究表明”“专家认为”等模糊归因代替来源。 |
| 局限与建议 | 已观察的失败条件、数据缺口或验证边界 | 写明影响的方向或场景，避免空泛的“仍有提升空间”。 |

### 第二轮：段落结构与论证节奏

每个子问题按“任务—输入与假设—模型—求解—证据—解释—局限”组织，但不机械地让每节段落数、句长或结尾句式完全相同。段落应由一个可验证的中心判断驱动；背景、方法、结果和解释不要在同一段中来回跳转。

优先删除不增加证据的信息性前言、重复性的章节预告和泛化的收束语。保留必要的学术衔接词；只有当同一段堆叠、或后面没有数据/公式/引用支撑时，才改写“此外”“值得注意的是”“综上”等衔接语。不要为了“去重”而替换已定义的模型名、变量、评价指标或术语。

### 第三轮：句子级精修

保持数学论文正式、克制的语气。每次只改能明确说明理由的句子，并在修改后复核符号、数字、单位、引用和推断强度。优先使用明确主语与可核验动词，例如“表 4 显示”“在 20% 扰动内目标值变化不超过 3.1%”“约束 (7) 排除了不可行方案”。

| 常见问题 | 审阅动作 |
|---|---|
| 重要性膨胀 | 将“关键、突破性、显著推动、里程碑”等评价语替换为结果、差异或限制；统计显著性只在给出检验与口径时使用。 |
| 空泛的结果解释 | 用“指标—数值—情景—含义”替代“效果良好、具有较强实用价值”。 |
| 悬空归因 | 为“已有研究/专家/实践证明”补充可核验来源；无法补充则删去。 |
| 假设被写成事实 | 用“在假设 A 下”“模型预测”“样本内观察到”明确认识边界。 |
| 过度因果或最优性 | 只有具备因果识别时才写“导致”；只有求解状态、约束与比较范围均明确时才写“最优”。其余使用“相关”“在本设定下更优”或“模型结果表明”。 |
| 多层模糊限定 | 让每项推断保留与证据相称的一层限定，不叠加“可能表明、或许、具有潜在”等空泛缓冲。 |
| 压缩且不可读的术语串 | 展开为变量之间的关系、过程或约束；技术标签和首次定义过的术语除外。 |
| 公式后无解释 | 补一句说明该式对应的题意、控制的关系或可解释输出，而不是重复朗读公式。 |
| 结论口号化 | 用主要数值发现、适用场景和一个具体局限收束，不写未经验证的长期影响或泛泛展望。 |

不要机械删除某个词、连词、破折号或句式。单个措辞不是“AI 痕迹”的证据；只有它造成重复、模糊、夸张或与证据不匹配时才需要修改。不得用人为错别字、无关口语、伪造犹豫或刻意不规则格式来制造“人工感”。

## 修订产物与停止条件

对实质性修订，保留简短变更卡，包含原句或段落定位、问题类别、证据位置、修改理由和修改后文本。优先返回局部差分，而不是在不说明原因的情况下整篇改写。

> **停止条件：** 当所有核心主张已回链，语气与证据强度匹配，术语和数字一致，且没有可验证理由支持进一步修改时，停止润色。不要无限轮改，也不要输出检测分数或“通过率”。

## 终检清单

- 每一个结论性段落是否至少包含可回链的结果、条件或引用？
- 是否清楚区分题设事实、数据观察、模型假设、计算结果和解释性推断？
- 是否保留模型的失败条件、适用范围和重要局限？
- 是否避免以词表替换代替事实核验，且没有添加任何未验证数字、来源或经历？
- 是否确保摘要、正文、图表、附录和代码输出的数值与术语一致？
