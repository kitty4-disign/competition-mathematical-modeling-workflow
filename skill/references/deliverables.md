|---|---|---|---|---|---|

|---|---|---|---|---|

## 数据质量记录

## D. 实验与验证记录

```markdown
| 实验 ID | 目的 | 数据/情景 | 参数 | 指标 | 结果 | 结论 |
|---|---|---|---|---|---|---|

## 最低验证清单
- [ ] 与基线或简单规则比较
- [ ] 约束可行性/量纲/边界检查
- [ ] 灵敏度分析
- [ ] 替代模型或关键假设对比
- [ ] 极端情景或外推风险检查
- [ ] 误差、残差或不确定性说明
```

## E. 决策日志

```markdown
| 日期/阶段 | 决策 | 依据 | 被排除的替代方案 | 影响的结果/文件 |
|---|---|---|---|---|
```

## F. 最终提交清单

```markdown
- [ ] 所有子问题均有明确回答。
- [ ] 变量、符号、单位和缩写已首次定义。
- [ ] 表图、正文、附录的数值一致且可复算。
- [ ] 每个模型都有假设、公式、求解方法和验证。
- [ ] 所有关键结论都有图、表、实验或推导支持。
- [ ] 局限与适用范围明确，不夸大结论。
- [ ] 代码、数据说明、随机种子和环境信息可复现。
- [ ] 论文格式、匿名/命名、页数和文件格式符合当届规则。
```
